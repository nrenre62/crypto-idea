# Bug-hunt reports

Dated reports produced by `/jira-bug-hunt` land here as `BUG-HUNT-<YYYY-MM-DD>.md` — findings only,
never fixes. Pipeline and rules: [`JIRA-WORKFLOW.md`](../JIRA-WORKFLOW.md) §10. Confirmed findings
become Jira Bugs (label `bug-hunt`) after explicit approval; approved fixes run through
`/jira-fix` and land in [`ERRORS.md`](../ERRORS.md).
