Admin Settings, rebuilt in the app's own design

Today the admin Settings tab is a flat scroll of grey, inline-styled cards in a visual language of its own. This proposal rebuilds it with the app's paper design system — the same headings, cards, switches, segmented controls and deep-green accent your users already meet in Account — and borrows the Account screen's drill-in list, so a long settings page becomes a short, scannable home.

Same tokens as src/styles/app.css: the iOS-style drill-in list, the pill switch, field-input rows and the green accent — nothing new invented. Try light and dark →
